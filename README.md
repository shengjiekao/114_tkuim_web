# Campus Event Registration & Management System
(校園活動報名與管理系統)

## Project Overview
This project is a complete **Campus Event Registration & Management System** designed to allow students to browse and register for events while providing administrators with tools to manage events and view registrations.

## Features
### Student (User)
- Browse all events.
- View detailed event information.
- Register for events.
- View personal registration history.
- Cancel registrations.

### Admin (Organizer)
- Create, Edit, and Delete events.
- specific View event registration lists.

## Tech Stack
### Backend
- **Node.js** & **Express.js**: RESTful API server.
- **MongoDB** & **Mongoose**: Database for Users, Events, and Registrations.
- **Service Pattern**: For business logic encapsulation.

### Frontend
- **React**: Component-based UI.
- **Tailwind CSS**: Utility-first styling for responsive design (RWD).
- **Axios**: API integration.

## Project Structure
- `/client`: React Frontend
- `/server`: Node.js Backend
