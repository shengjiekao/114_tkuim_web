# PTT Web Clone (批踢踢實業坊網頁版)

這是一個模仿台灣知名 BBS 站台「批踢踢實業坊 (PTT)」的網頁版專案。此專案重現了經典的黑色終端機介面風格，並提供了現代化的網頁互動體驗。

##  特色 (Features)

*   **經典介面重現**: 採用黑色背景與亮綠/青色文字，還原 BBS 終端機視覺體驗。
*   **深色模式 UI**: 專為長時間閱讀設計的 Dark Mode 介面。
*   **熱門看板**: 首頁展示熱門看板卡片，包含即時人氣數據 (模擬)。
*   **看板列表**: 條列式展示所有看板，支援詳細資訊瀏覽。
*   **搜尋功能**: 導覽列內建即時搜尋列，可透過看板名稱、類別或標題快速篩選看板。
*   **模擬登入系統**:
    *   點擊「登入」按鈕可模擬使用者登入 (預設帳號: guest)。
    *   包含年齡驗證模擬機制 (例如進入 Gossiping 板)。
    *   狀態列即時顯示目前使用者身分。
*   **互動式 Modal**: 點擊看板會有模擬連線的系統訊息視窗。

##  技術棧 (Technologies)

*   **HTML5**: 建構語意化的網頁結構。
*   **CSS3**: 使用 CSS Variables 管理主題顏色，Flexbox 與 Grid 佈局實現響應式設計。
*   **JavaScript (Vanilla JS)**: 處理動態資料渲染 (Mock Data)、搜尋邏輯、DOM 操作與互動事件。

##  如何使用 (Usage)

1.  確認資料夾中包含 `ptt.html`, `style.css`, `script.js` 三個檔案。
2.  直接使用瀏覽器 (Chrome, Edge, Firefox 等) 開啟 `ptt.html` 即可。
3.  **體驗功能**:
    *   輸入關鍵字搜尋看板。
    *   點擊右上角「登入」體驗模擬登入流程。
    *   點擊任一看板卡片或列表項目體驗模擬連線。

##  檔案結構

*   `ptt.html`: 主頁面結構。
*   `style.css`: 樣式表。
*   `script.js`: 邏輯控制與假資料 (Mock Data)。
*   `todo.md`: 開發待辦清單 (已完成)。
